# Sybos transfer

The "Sybos transfer" page prepares an operation so it can be copied into the Sybos operation report. Each field has its own copy button.

## Features

- **Basic data:** operation, fire brigade, start, alarm, arrival, end, duration, location and description
- **Course of operation:** AI summary split into "course of operation" and "activities / remarks"
- **Forces and equipment:** own vehicles with strength and times, crew by name, other forces (ambulance, police, other fire brigades) and equipment used
- **Other notes:** operation sites with notes and the business log
- **Operation diary:** all entries, one line per entry
- **Copy all:** the whole report at once

## Instructions

1. In the menu under "Operation documentation", click "Sybos transfer"
2. Under "Course of operation", click "Create with AI"
3. Check the text and correct it directly in the field if needed — changes are saved
4. Copy field by field using the copy icon and paste into Sybos

## Notes

- The AI text only uses the recorded operation data. The more complete the diary, vehicles and sites, the better the summary.
- Always check the text before transferring it.
- "Recreate" overwrites the existing texts.
