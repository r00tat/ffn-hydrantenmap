# Keyboard shortcuts

On a PC you can reach the most important functions of the operations map with the keyboard – without menu and mouse. Press **?** for an overview of all shortcuts at any time.

## Features

- **Search with /** across map items, operation sites, operational diary, business logbook and pages
- **New entries** in the operational diary (**T**) and business logbook (**G**) from any page
- **Map**: place a marker, add a vehicle, operation site, hose line or area, toggle editing
- **Navigation** with Shift + letter to map, diary, business logbook and other pages
- **Your own key assignment** per device under Menu → Help & Account → Keyboard shortcuts

## The shortcuts

| Key | Function |
| --- | --- |
| / | Open search |
| ? | Keyboard shortcut overview |
| T | New operational diary entry |
| G | New business logbook entry |
| M | Place marker (on the map) |
| F | Add vehicle (on the map) |
| O | Place operation site (on the map) |
| L | Draw hose line (on the map) |
| A | Draw area (on the map) |
| N | Add element, choosing the type (on the map) |
| E | Toggle editing (on the map) |
| Shift + K | Go to map |
| Shift + T | Go to operational diary |
| Shift + G | Go to business logbook |
| Shift + E | Go to resources |
| Shift + O | Go to operation sites |
| Shift + L | Go to layers |
| Shift + H | Go to operation list |
| Alt + Shift + B | Bug report with screenshot |

On a Mac, Alt is called Option (⌥) and Shift is shown as ⇧.

## How to

### Search

1. Press **/**
2. Type a search term, e.g. a vehicle name, an address or a word from a diary entry
3. Choose with the arrow keys and open with **Enter** – or simply click

A map item is shown and selected; a diary or business logbook entry is highlighted on its page.

### Place a marker quickly

1. Press **M** on the map
2. The marker follows the mouse – click to drop it, press **Esc** to cancel

The marker gets a name like "Marker 4" and lands on the layer you chose last. Change name, symbol and description afterwards as usual. On a tablet it is dropped right away at the map centre or your position.

### Add a vehicle, operation site, hose line or area

Press **F**, **O**, **L** or **A** on the map: the dialog opens with the matching type. Draw hose lines and areas on the map afterwards as usual.

If editing is off, the shortcut switches it on.

### Change or switch off shortcuts

1. Menu → Help & Account → **Keyboard shortcuts**
2. Choose **Change** next to a function and press the new key combination (**Esc** cancels)
3. The block icon switches a shortcut off, the arrow resets it to the default

A switch at the top turns all shortcuts off. If a key is assigned twice, the page shows a warning.

## Notes

- **Settings apply per device.** The command post PC can use a different assignment than your laptop.
- **Single keys rest while you type.** While you write in an input field or a dialog is open, letters, / and ? do nothing.
- **Map shortcuts only work on the map** and only if you may write to the operation.
- **T and G** need a selected operation.
