# Tastenkürzel

Am PC erreichst du die wichtigsten Funktionen der Einsatzkarte mit der Tastatur – ohne Menü und ohne Maus. Mit **?** siehst du jederzeit eine Übersicht aller Kürzel.

## Funktionen

- **Suche mit /** über Elemente der Karte, Einsatzorte, Einsatztagebuch, Geschäftsbuch und Seiten
- **Neue Einträge** im Einsatztagebuch (**T**) und Geschäftsbuch (**G**) von jeder Seite aus
- **Karte**: Marker setzen, Fahrzeug, Einsatzort, Leitung und Fläche anlegen, Bearbeiten ein und aus
- **Navigation** mit Umschalt + Buchstabe zu Karte, Tagebuch, Geschäftsbuch und weiteren Seiten
- **Eigene Belegung** je Gerät unter Menü → Hilfe & Konto → Tastenkürzel

## Die Kürzel

| Taste | Funktion |
| --- | --- |
| / | Suche öffnen |
| ? | Übersicht der Tastenkürzel |
| T | Neuer Einsatztagebuch-Eintrag |
| G | Neuer Geschäftsbuch-Eintrag |
| M | Marker setzen (auf der Karte) |
| F | Fahrzeug hinzufügen (auf der Karte) |
| O | Einsatzort setzen (auf der Karte) |
| L | Leitung zeichnen (auf der Karte) |
| A | Fläche zeichnen (auf der Karte) |
| N | Element hinzufügen mit Typauswahl (auf der Karte) |
| E | Bearbeiten ein/aus (auf der Karte) |
| Umschalt + K | Zur Karte |
| Umschalt + T | Zum Einsatztagebuch |
| Umschalt + G | Zum Geschäftsbuch |
| Umschalt + E | Zu den Einsatzmitteln |
| Umschalt + O | Zu den Einsatzorten |
| Umschalt + L | Zu den Ebenen |
| Umschalt + H | Zur Einsatzliste |
| Alt + Umschalt + B | Bug-Report mit Screenshot |

Auf dem Mac heißt Alt „Option" (⌥) und Umschalt „⇧".

## Anleitung

### Suchen

1. **/** drücken
2. Suchbegriff tippen, etwa einen Fahrzeugnamen, eine Adresse oder ein Wort aus einem Tagebucheintrag
3. Mit den Pfeiltasten wählen und mit **Enter** öffnen – oder einfach anklicken

Ein Element der Karte wird angezeigt und ausgewählt, ein Tagebuch- oder Geschäftsbuch-Eintrag wird auf seiner Seite markiert.

### Schnell einen Marker setzen

1. Auf der Karte **M** drücken
2. Der Marker hängt an der Maus – mit einem Klick absetzen, mit **Esc** abbrechen

Der Marker bekommt einen Namen wie „Marker 4" und landet auf der zuletzt gewählten Ebene. Name, Symbol und Beschreibung änderst du danach wie gewohnt. Auf einem Tablet wird er gleich in der Kartenmitte bzw. an deiner Position gesetzt.

### Fahrzeug, Einsatzort, Leitung oder Fläche anlegen

Auf der Karte **F**, **O**, **L** oder **A** drücken: Der Dialog öffnet sich gleich mit dem passenden Typ. Leitungen und Flächen zeichnest du danach wie gewohnt auf der Karte.

Ist der Bearbeitungsmodus aus, schaltet ihn das Kürzel selbst ein.

### Kürzel ändern oder ausschalten

1. Menü → Hilfe & Konto → **Tastenkürzel**
2. Bei einer Funktion **Ändern** wählen und die neue Tastenkombination drücken (**Esc** bricht ab)
3. Mit dem Sperr-Symbol schaltest du ein Kürzel ab, mit dem Pfeil setzt du es auf die Vorgabe zurück

Ein Schalter oben stellt alle Kürzel ab. Ist eine Taste doppelt belegt, zeigt die Seite einen Hinweis.

## Hinweise

- **Einstellungen gelten je Gerät.** Am Einsatzleitstand-PC kannst du anders belegen als am Laptop.
- **Beim Tippen ruhen einfache Tasten.** Solange du in einem Eingabefeld schreibst oder ein Dialog offen ist, lösen Buchstaben, / und ? nichts aus.
- **Kürzel der Karte gelten nur auf der Karte** und nur, wenn du im Einsatz schreiben darfst.
- **T und G** brauchen einen gewählten Einsatz.
